# Python lernen – Startseite

## Schnell finden

- **⌘P**: Datei nach Namen oeffnen, zum Beispiel `fibonacci`, `factorial`, `counter` oder `palindrome`.
- **⇧⌘F**: In allen Uebungen nach einem Begriff wie `nonlocal`, `yield` oder `sqlite3` suchen.
- **⇧⌘O**: In der aktuellen Python-Datei zu einer Funktion oder Klasse springen.
- Diese Startseite als Vorschau mit **⇧⌘V** oeffnen und ein Thema anklicken.

## Ablageregeln

- Neue Uebungen beim passenden Thema speichern; sprechende Dateinamen in `snake_case.py` verwenden.
- Zusammengehoerige Spiele, Module und ihre Daten zusammenlassen.
- `10_practice` fuer themenuebergreifende Versuche nutzen; neue Aufgaben spaeter fachlich einsortieren.
- Die Themenverzeichnisse bilden den Stand der Neuordnung ab. Neue Dateien erscheinen sofort im Explorer und in der Dateisuche; Links bei Bedarf ergaenzen.
